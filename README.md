# CImageOptimizer

[![Build](https://github.com/MithunKiet/windows-image-optimizer/actions/workflows/build.yml/badge.svg)](https://github.com/MithunKiet/windows-image-optimizer/actions/workflows/build.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

CImageOptimizer is a Windows desktop GUI application for optimizing, resizing, and copying image files safely.

## Features

- Select a source folder, **or** pick individual files instead ("Or Select
  Individual Files..."), plus an output folder, from a simple GUI.
- Optimize `.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`, `.tif`, and `.tiff` files.
- Choose a **Safe / Recommended / Advanced** profile to control how aggressively images are compressed.
- Resize very large images (down to each profile's max width, `1920px` by
  default), or check **Keep original resolution** to only compress without
  ever changing dimensions.
- JPEG and WEBP are compressed with a real quality search; PNG/BMP/TIFF (which
  have no lossy "quality" in the first place) get one optimized lossless
  pass, with an optional **Convert oversized PNG/BMP/TIFF to JPEG** fallback
  if a lossless image is still over the size target.
- Copy non-image files without modifying them.
- Process files concurrently with a bounded thread pool.
- Incremental runs: files already present in the output folder are skipped
  by default; check **Overwrite existing files** to reprocess them instead.
- Show live progress, cancel a running batch, and view processing logs.
- Export a JSON or CSV report of what was processed after a run.
- Remembers your last-used folders, mode, profile, and option checkboxes
  (`settings.json`) - individual file selections are not remembered, since
  the files may not exist on the next launch.
- Build a standalone Windows `.exe`.
- Build a Windows installer with Desktop shortcut, Start Menu shortcut, and uninstall support.

## Project Structure

```text
windows-image-optimizer/
|-- main.py                         # Thin GUI entry point (kept at root for PyInstaller)
|-- assets/                         # App icon (icon.ico / icon.png)
|-- cimageoptimizer/                # Application package (Clean-Architecture-style layers)
|   |-- core/                       # Constants, enums, exceptions, dataclasses - no I/O
|   |-- application/services/       # Discovery, compression, orchestration, report export
|   |-- infrastructure/             # Filesystem, logging, settings.json persistence
|   `-- presentation/gui/           # Tkinter App
|-- tests/                          # pytest suite for the application/core layers
|-- requirements.txt                # Runtime dependencies (pinned)
|-- requirements-dev.txt            # Runtime + test dependencies
|-- installer/
|   |-- build-installer.ps1         # Builds the Windows installer
|   |-- Setup.cs                    # Installer source code
|   `-- Uninstall-CImageOptimizer.ps1
|-- .github/workflows/build.yml     # CI: tests + packaging sanity build
|-- build/                          # Generated by PyInstaller
`-- dist/                           # Generated EXE and installer output
```

See [ARCHITECTURE.md](ARCHITECTURE.md) for how the layers fit together.

## Requirements

- Windows
- Python installed and available from PowerShell
- `pip`
- .NET Framework C# compiler, included on most Windows systems

The installer build script uses:

```text
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
```

If that path is not available, it automatically tries:

```text
C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe
```

## Step 1: Open PowerShell

Open PowerShell normally. Admin mode is not required.

## Step 2: Go To The Project Folder

Run:

```powershell
cd C:\Users\240135357\Downloads\CImageOptimizer
```

Important: run the commands from the project folder. If you are in `C:\Windows\System32`, relative paths like `installer\build-installer.ps1` will not work.

## Step 3: Install Dependencies

Run:

```powershell
pip install -r requirements.txt
```

This installs:

```text
Pillow
tqdm
pyinstaller
```

For development (running the test suite), use `requirements-dev.txt` instead, which additionally installs `pytest`:

```powershell
pip install -r requirements-dev.txt
```

## Step 4: Run The App In Development

Run:

```powershell
python main.py
```

Use this command when you want to test the app before creating the `.exe` or installer.

## Step 5: Build The Standalone EXE

Run:

```powershell
pyinstaller --noconsole --onefile --icon assets\icon.ico main.py
```

After the build finishes, this file is created:

```text
dist\main.exe
```

You can run it directly:

```powershell
.\dist\main.exe
```

## Step 6: Build The Windows Installer

Make sure `dist\main.exe` exists first.

Then run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\installer\build-installer.ps1
```

After the build finishes, this file is created:

```text
dist\CImageOptimizer-Setup.exe
```

## Step 7: Build Installer From Any Folder

If your PowerShell is currently in another folder, such as `C:\Windows\System32`, use the full path:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File C:\Users\240135357\Downloads\CImageOptimizer\installer\build-installer.ps1
```

The output is still created here:

```text
C:\Users\240135357\Downloads\CImageOptimizer\dist\CImageOptimizer-Setup.exe
```

## Step 8: Install The App

Run the installer:

```powershell
.\dist\CImageOptimizer-Setup.exe
```

The installer copies the app to:

```text
%LOCALAPPDATA%\Programs\CImageOptimizer
```

It also creates:

```text
Desktop shortcut
Start Menu shortcut
Windows Apps & Features uninstall entry
```

## Step 9: Uninstall The App

Use either method:

```text
Windows Settings > Apps > Installed apps > CImageOptimizer > Uninstall
```

Or use the Start Menu shortcut:

```text
Start Menu > CImageOptimizer > Uninstall CImageOptimizer
```

## Troubleshooting

### `installer\build-installer.ps1` does not exist

You are probably not inside the project folder.

Fix:

```powershell
cd C:\Users\240135357\Downloads\CImageOptimizer
```

Then run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\installer\build-installer.ps1
```

### `pyinstaller` is not recognized

Install the dependencies:

```powershell
pip install -r requirements.txt
```

If it still fails, try:

```powershell
python -m PyInstaller --noconsole --onefile --icon assets\icon.ico main.py
```

### `dist\main.exe` is missing

Build the standalone app first:

```powershell
pyinstaller --noconsole --onefile --icon assets\icon.ico main.py
```

### PowerShell execution policy error

Use the provided command with `-ExecutionPolicy Bypass`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\installer\build-installer.ps1
```

### Installer compiler not found

The installer script requires the .NET Framework C# compiler. Check whether one of these files exists:

```text
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe
```
